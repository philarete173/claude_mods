Visualized pane

The Session block holds the context core with eight stations, four on each side: Model, Files, Shell and Web to the left; Agents, MCP, Skills and You to the right. A pulse runs from the core to the station of each new call. Under a ~500 px pane each side forks into two rows of two; wider, one row of four; on a wide pane the core stays in the middle and each side’s stations reach the band’s edge. The turn ribbon replaces the Turn stats table (the table stays behind ‘details’), and the Activity lanes replace the Subagents and Tasks lists; every colour in them is a station colour from the Session block. Context sources stays.
